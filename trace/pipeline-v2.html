Chaining Rules

  • Subagents CAN spawn sub-subagents (deep chaining)
  • Subagents CANNOT invoke slash commands
  • Parallelize all independent work -- waves
  • Per-agent tool allowlists
  • Haiku for scanning, Sonnet for coding, Opus when needed
  • Escalate only on genuine blockers
  • Implementers ALWAYS run tests
  • Chained Ralph: PARTIAL -- 2nd implementer
  • Wave execution default for multi-step
  • Sidecars for non-blocking work
  • Cross-wave data flows forward
  • Sidecar failures are non-fatal

Anti-Patterns

  • Skip wheel-scout gate for build tasks
  • Orchestrate trivial one-file fixes
  • Load all skills (router picks 1-3)
  • Send full codebase to subagents
  • Duplicate research across agents
  • Create both MCP + skill for same thing
  • Forget to checkpoint memory
  • Single-pass "implement and pray"
  • Rewriting everything on test failure
  • Infinite-looping same bug
  • Serialize independent sub-tasks
  • Block main pipeline for non-critical sidecar
